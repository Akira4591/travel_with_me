# S2 Completion Gap Review

日期：2026-06-19

## 结论

当前项目已从 S1 私测闭环进入 S2 差异化验证收口状态。代码层已补齐 AI 导入评测、分享隐私选项、3D 地形模式、地形可信度、3D/2D 标记、分享图标记选项和浏览器回归验证。

仍不能宣称完全商业化验证完成：真实用户攻略样本、真实分享传播反馈、真实景区/徒步地形反馈需要用户样本或外部数据源，不能由本地代码伪造。

## 已修复差距

| 设计目标                 | 修复状态                                                                 | 验证                            |
| ------------------------ | ------------------------------------------------------------------------ | ------------------------------- |
| AI 导入要可量化          | 评测集扩展到 12 个 case / 64 个标注地点                                  | `npm.cmd run test:guide-import` |
| 分享内容要有隐私边界     | 备注、交通、未排期、3D 标记均由用户选择                                  | Playwright 分享预览回归         |
| 3D 不能只展示            | `chooseTerrainMode()`、`TerrainModel`、地形摘要、annotation layer 已落地 | Playwright 3D smoke             |
| 3D 标记要可产生数据      | Raycaster 点击地形，弹窗确认后写入 `trip.annotations[]`                  | Playwright 点击创建标记         |
| 2D/3D/分享要共享标记数据 | 2D marker、3D marker、分享图均读取同一 `annotations[]`                   | 单测 + E2E                      |
| 高程失败不能过度承诺     | `flat-fallback` 下只展示降级，不输出坡度结论                             | 代码路径 + E2E 属性             |

## 剩余真实验证项

| 项目                       | 当前处理                                      | 后续阶段        |
| -------------------------- | --------------------------------------------- | --------------- |
| 20-30 篇真实中文攻略       | 已有 12 个种子回归 case，真实样本继续采集     | S2 私测运营     |
| 景区/徒步 DEM 精度         | Open-Meteo 分块 + 可信度提示，DEM tile 未接入 | S3/S2 进阶      |
| 只读短链接和复制到我的行程 | 当前仍以本地长图分享和旧 `#trip=` 兼容为主    | S3 云端分享     |
| 标记聚焦相机、长按轮盘     | 当前完成点击创建和编辑面板                    | S2 后续体验打磨 |
| 真实传播反馈               | 需要真实用户分享图/3D 标记使用记录            | S2 私测         |

## 当前推荐判断

- 可以继续给桌面端 Web 私测用户验证 S2 差异化能力。
- 不应进入付费墙或大规模投放，直到真实攻略样本、分享传播反馈和 3D 标记使用反馈至少完成一轮。
- 不应重启移动 Web 深度开发；后续移动端仍按 Kotlin 原生 Android 单独评估。
